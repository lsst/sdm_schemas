# SDM Schemas

The Science Data Model (SDM) schemas define the user-facing data catalogs of the [Vera C. Rubin Observatory](https://rubinobservatory.org/): the tables and columns of its databases, along with their keys, indexes and other database objects.
They are the source of truth for these data models.

In the schema browser, you can explore each schema and search across all of them.

```{button-link} browser/index.html
:color: primary

Browse the schemas
```

The schemas are YAML files read by [Felis](https://felis.lsst.io), which generates SQL DDL, [TAP_SCHEMA](https://www.ivoa.net/documents/TAP/20190927/REC-TAP-1.1.html#tth_sEc4) and other formats from them, and is responsible for validating their contents.
The schema browser is also generated by Felis, as described in its [schema browser documentation](https://felis.lsst.io/user-guide/browser.html).

The schemas are developed on GitHub at <https://github.com/lsst/sdm_schemas>.
