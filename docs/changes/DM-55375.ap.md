Applied RFC-1188 to the PPDB Solar System tables. The PPDB's `SSSource` is renamed `SSObservation` (the alert's SSSource is unchanged) and is now built from the record of measurements submitted to the MPC: one row per accepted observation, keyed by `obs_sbn.obsid`, carrying the full measurement it was submitted from (a DiaSource or a Source; see `measuredOn`) and the predicted position's error ellipse (`ephRaErr`, `ephDecErr`, `ephRa_ephDec_Cov`). Added the `NearbySSO` table.
