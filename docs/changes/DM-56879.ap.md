Added `pixelFlags_spike` to the `DiaSource` table in `apdb.yaml` and `ppdb.yaml`, set when the diaSource footprint includes pixels on a predicted diffraction spike of a bright star.
Added `templateMjdMean`, `templateMjdMin` and `templateMjdMax` to the `DiaSource` table in `apdb.yaml` and `ppdb.yaml`: the weighted mean, earliest and latest mid-exposure times of the template input images that cover the diaSource centroid.
Added `templateInstrument`, `templateVersion` and `mixedInstruments` to the `DiaSource` table in `apdb.yaml` and `ppdb.yaml`: the instrument recorded for the template, the version of the template, and whether the template is from a different instrument than the diaSource.
