# Change categories

The [release notes](changelog.md) group changes by the type of schema affected.
The patterns for naming the schemas of each type are described in [Schema types](schemas.md).

**Data Releases** - Data Preview and Data Release schemas

**Science Pipelines** - Schemas which are managed through continuous integration with the Science Pipelines

**Solar System Production** - Solar System Production schemas

**Alert Production and Prompt Products** - Alert Production Database (APDB) and Prompt Products Database (PPDB) schemas, and other related schemas, used in nightly data processing

**Consolidated Database** - Consolidated Database of Image Metadata (ConsDB) and Transformed EFD schemas

**Miscellaneous** - Catch-all category for changes which are not related to particular schemas, typically involving changes to GitHub workflows, project scripts, etc.
